# DATATYPE.CableLabels — Cable & Panel Label Wizard

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Cable & Panel Label Wizard: formats signal cable tags (source, destination, signal type, wire number) and patch panel designation strips for Avery label sheets, Brother P-Touch printers, and Brady thermal stock.

| | |
|---|---|
| **Opens** | the OS shell (Pipeline → Translators & Formats), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/DATATYPE/DATATYPE.CableLabels/` |
